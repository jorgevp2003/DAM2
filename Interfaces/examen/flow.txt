PROYECTO BASE EXAMEN (JavaFX + Maven)
=====================================

COMANDOS
--------
  mvn clean javafx:run     -> ejecuta la app
  mvn clean test           -> ejecuta los tests JUnit 5
  mvn -o clean test        -> igual pero SIN internet (todo está en ~/.m2)
  VS Code: Run "Ejecutar examen (Lanzador)" (.vscode/launch.json)

Requisitos: JDK 21 o superior (probado con 21 y 25), Maven 3.6+.
Para crear un proyecto nuevo: copiar esta carpeta entera y cambiar en pom.xml
artifactId, name y javafx.mainClass.

ESTRUCTURA
----------
src/main/java/es/ciudadescolar/
  Main.java                      extends Application. Carga /fxml/principal.fxml + /css/estilos.css
  Lanzador.java                  main() sin Application -> llama a Main.main (para el botón Run del IDE)
  modelo/Persona.java            Modelo (datos + getEdad() calculada + toString)
  util/Validador.java            Validaciones estáticas SIN JavaFX (DNI, email, teléfono, edad, rango...)
  util/Alertas.java              info / error / aviso / confirmar (Alert)
  componentes/CampoTexto.java    VBox(Label+TextField): obligatorio, regla Predicate, borde rojo, textProperty
  componentes/BotonAccion.java   Button: colorFondo, colorTexto, tamañoTexto, Tooltip, activo. Usable en FXML
  controlador/PrincipalController.java   Controlador del FXML (@FXML, initialize, TableView, listeners)
  vista/FormularioView.java      Vista hecha por CÓDIGO (GridPane con CampoTexto + BotonAccion)
  controlador/FormularioController.java  Controlador MVC de FormularioView
src/main/resources/
  fxml/principal.fxml            BorderPane: formulario (TextField, DatePicker, ComboBox, RadioButton+ToggleGroup,
                                 CheckBox, TextArea), TableView, botones, label estado
  css/estilos.css                Clases .titulo, .estado, etc.
src/test/java/es/ciudadescolar/
  FxTestUtil.java                iniciarJavaFX() (una vez por JVM) + ejecutarEnFX(Runnable)
  util/ValidadorTest.java        Tests puros + @ParameterizedTest
  componentes/CampoTextoTest.java, BotonAccionTest.java   Tests en hilo JavaFX
  controlador/PrincipalFxmlTest.java   Comprueba que el FXML carga y enlaza el controlador

FLUJO (quién llama a quién)
---------------------------
Lanzador.main -> Main.main -> Application.launch -> Main.start
  Main.start -> FXMLLoader(principal.fxml)
      FXML crea los nodos, instancia PrincipalController (fx:controller),
      inyecta los @FXML por fx:id y llama a initialize()
  PrincipalController.initialize
      - rellena ComboBox, enlaza columnas TableView -> getters de Persona (PropertyValueFactory)
      - tabla.setItems(ObservableList<Persona> personas)
      - listeners en cada campo -> actualizarEstado()
            actualizarEstado -> Validador.* -> marca bordes, activa/desactiva btnGuardar, texto lblEstado
      - bind: btnEliminar deshabilitado si no hay fila seleccionada
  Botones (onAction="#metodo" en el FXML):
      guardar()   -> comprobarErrores() (Validador) -> new Persona -> personas.add -> tabla se refresca -> Alertas.info
      limpiar()   -> vacía todos los controles
      eliminar()  -> Alertas.confirmar -> personas.remove
      abrirFormularioMvc() -> new FormularioView() + new FormularioController(vista, personas)
                              -> Stage modal. Lo que se guarda ahí se añade a la MISMA lista -> aparece en la tabla
  Doble clic en fila -> Alertas.info(persona.toString())

FormularioController (MVC por código):
  constructor -> setOnAction de botones, setOnMouseEntered/Exited, listeners en CampoTexto.textProperty()
  actualizarEstado -> Validador.esDniValido + longitudes -> BotonAccion.setActivo + lblEstado
  guardarPersona -> new Persona(nombre, apellidos, dni) -> lista compartida
