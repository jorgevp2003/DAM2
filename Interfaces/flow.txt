INTERFACES - FLUJO GENERAL
==========================

Todos los proyectos usan el MISMO pom.xml (solo cambian artifactId, name y javafx.mainClass):
  - Java release 21 (funciona con JDK 21, 25, 27...)  -> enforcer exige [21,)
  - JavaFX 23 (controls + fxml), JUnit Jupiter 5.10.0 (test)
  - Plugins: enforcer 3.6.2, compiler 3.11.0, surefire 3.5.4, javafx-maven-plugin 0.0.8
  - groupId es.ciudadescolar
Todas las versiones están en ~/.m2 -> compila sin internet (mvn -o).

pom.xml (raíz) = agregador: "mvn clean verify" compila y testea todos los proyectos.

PROYECTOS                    mainClass                    Contenido
ejercicio1/ejercicio1        com.example.Main             FXML alta empleado + validaciones
Practica-2/practica2         es.ciudadescolar.Main        FXML reservas (SplitPane)
practica-3/practica3         es.ciudadescolar.Main        Componente BotonAccion + tests + Javadoc + BotonAccion.jar
practica-3/PruebaBotonAccion com.ejemplo.Main             Usa BotonAccion.jar (lib/systemPath): registro incidencias MVC
                             (detalle de la práctica 3 en practica-3/flow.txt)
practica-3/practica3_1       com.example.Main             Ventana mínima JavaFX
tema3                        es.ciudadescolar.Main        Componente CampoTexto
tema3-2                      es.ciudadescolar.Main        MVC por código + tests CampoTexto/DNI
examen                       es.ciudadescolar.Main        PROYECTO BASE con todo lo anterior (ver examen/flow.txt)

Ejecutar uno:  cd <proyecto> && mvn clean javafx:run
   o desde la raíz:  mvn clean javafx:run -pl <proyecto>   (ej: -pl examen)
